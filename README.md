# tutor-tic-medicina
Tutor de estudio con IA para Tecnología de la Información y Comunicación, Medicina 1.er nivel (UTA). Contenidos de las 4 unidades, talleres PAE 1 a 6, autoevaluación y fichas sobre comunicación, búsqueda científica, Excel y divulgación en salud. La IA funciona con la clave gratuita de Gemini de cada estudiante.
